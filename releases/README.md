# Still 1.2.1 for Android

Sign in to GitHub on your phone and open the [Still 1.2.1 release](https://github.com/eerihyppanen/Still/releases/tag/v1.2.1). Download `Still-1.2.1.apk` from Assets, open it, and choose Update or Install. **Keep the old app installed** so Android retains its local history. This build uses the same package and signing certificate as the previous test APKs.

- On Today, expand the completed row to review or undo check-ins.
- In History, the weekly recap shows your progress, most consistent routine, and hardest past days.
- In Habits → Reorder, drag the grip to change the order.
- The launcher icon, splash artwork, loading view, and Today header use the same leaf with a short stem.
- In a habit's edit form, choose Anytime, Morning, Afternoon or Evening.
- Expand a habit notification for Done and Snooze 10 min.
- Long-press your home screen → Widgets → Still → Still — Today to add the compact widget. It shows the saved date/progress; Open Still refreshes it and opens the app for check-ins.
- The installed app works without internet or a development server. This Android build has no internet permission and excludes app data from automatic backup/transfer. There is no account or cloud sync.

Uninstalling or losing the phone can lose local history. The update prevents future automatic backups; it cannot remove backups made by an earlier version.

SHA-256 is in `SHA256SUMS.txt`. Build and emulator evidence is recorded in `../VERIFICATION.md`.
