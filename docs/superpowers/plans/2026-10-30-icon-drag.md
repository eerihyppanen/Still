# Icon and Drag Reordering Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement task-by-task.

**Goal:** Improve the Still leaf and replace arrow tapping with live drag reordering.

**Architecture:** Editable SVG assets feed generated platform PNGs. A focused reorder component uses PanResponder and Animated transforms, pure variable-height geometry, and one atomic SQLite order save on drop.

**Tech Stack:** Existing Expo 58 / React Native 0.88 / TypeScript / SQLite.

**Spec:** ../specs/2026-10-30-icon-drag-design.md

## Global Constraints

- Preserve existing data/schema 1, offline policy and package/signing identity.
- No new APK, native regeneration or native library.
- Work in the explicitly requested Desktop folder; no Git metadata exists. Preserve originals locally instead of commits/worktrees.

## Review Focus

- Unequal heights/large text: insertion uses measured heights, never a fixed row estimate.
- Long lists: edge scrolling keeps the held row under the pointer and permits distant drops.
- Interrupted gestures/layout/background: reset without writing a partial order.
- Stale/invalid IDs and failed writes: reject atomically; restore the saved list.
- Assistive input: keyboard and accessibility actions can move rows without dragging.
